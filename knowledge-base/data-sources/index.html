    Free Sources¶

    Source Type Coverage Example Metrics Access Notes
    SEC EDGAR Filings US public companies 10-K/Q, insider Form 4, guidance vs actual No API key; use sec-api or edgar-online
    FRED Macro US & global macro Rates, spreads, CPI API key optional
    Yahoo Finance Market data Global Prices, P/E, EV/EBIT, PEG yfinance Python library
    Google Trends Consumer interest Global search Search index trends Free API (pytrends)
    App Store / Play Store Product ratings Apps NPS proxies, app version trends Scrape or API proxy
    Glassdoor / Indeed Employee sentiment Global Eng team ratings, CEO approval Web scraping; ToS-bound

    Data Sourcing Workflow¶

    1. Map each dashboard metric to a data source from this list.
    2. Select tier (free, paid, mixed) based on availability and budget.
    3. Automate fetching via scripts in /scripts/.
    4. Store raw data in /data/raw/{source}/{date}.csv.
    5. Process into normalized metric JSON for docs/data/dashboard.json.
    6. Audit source freshness and coverage quarterly.

    APIs & Automation¶

    • Python packages: yfinance, sec-api, pytrends, alpha_vantage, polygon
    • Schedule: Use cron or GitHub Actions for daily/weekly refresh
    • Cache: Keep local cache to avoid rate limits
    • Error handling: Fail gracefully; flag metrics as stale

    Legal & Compliance Notes¶

    • Respect Terms of Service for each source
    • Avoid scraping where prohibited
    • For investment use, retain attribution of data source
    • For public dashboards, strip proprietary fields unless licensed
