    🔍 Research & Edge¶

    Short Interest, PCR, Sentiment Divergence — Ignore the crowd (contrarian only with facts)

    Evaluation metrics - Short interest % of float, put/call ratio, sentiment vs. estimate revisions
    Method & thresholds - Flag when negative sentiment and improving 3-month EPS estimate revisions
    Signal - 🟢 SI% > 10% and EPS revisions ↑; 🟡 only one condition; 🔴 neither
    Weight / confidence - 0.6 / 0.6
    Data sources - NASDAQ Short Interest, CBOE Options Data, TipRanks Analyst Revisions

    Variant Perception, Edge Mapping — Own where you have a research edge

    Evaluation metrics - Count of independent proprietary inputs, coverage gaps, channel checks logged
    Method & thresholds - Require ≥3 unique, independent inputs
    Signal - 🟢 ≥3; 🟡 2; 🔴 ≤1
    Weight / confidence - 1.0 / 0.8
    Data sources - Internal research logs, Koyfin

    NPS, GRR/NRR, SLA — Best product wins

    Evaluation metrics - NPS trend, churn, uptime/status incidents
    Method & thresholds - NPS z-score > 0.8, churn < 5%
    Signal - 🟢 both pass; 🟡 one; 🔴 none
    Weight / confidence - 0.9 / 0.7
    Data sources - G2, Capterra, company status pages

    Guidance Delta, Insider Sell/Buy — Don’t listen to management (verify claims)

    Evaluation metrics - Guide vs. actual miss rate, insider transactions, risk language in transcripts
    Method & thresholds - Miss rate < 20%, sell/buy ratio < 2
    Signal - 🟢 both pass; 🟡 one; 🔴 none
    Weight / confidence - 0.7 / 0.7
    Data sources - SEC EDGAR, OpenInsider

    TAM Signals, Channel Checks — Study the full value chain

    Evaluation metrics - Supplier lead times, backlog, search trends
    Method & thresholds - Correlation with next-Q revenue > 0.5
    Signal - 🟢 > 0.5; 🟡 0.3–0.5; 🔴 < 0.3
    Weight / confidence - 0.6 / 0.6
    Data sources - Google Trends, freight indices, supplier filings

    💎 Quality & Growth¶

    Investment Thesis, KPIs — One-sentence thesis clarity

    Evaluation metrics - Thesis clarity score, KPI coverage %, risk checklist completion
    Method & thresholds - LLM rubric + checklist; require ≥ 90% checklist complete
    Signal - 🟢 ≥90%; 🟡 70–89%; 🔴 <70%
    Weight / confidence - 0.4 / 0.9
    Data sources - Your memo template; attach exhibits and KPI definition page

    Unit Economics, Operating Leverage, ROIC — Growth quality stack

    Evaluation metrics - Unit growth, pricing power, gross/operating margin expansion, reinvestment ROIC
    Method & thresholds - Decompose revenue bridge; unit growth > 10% and GM ↑ YoY
    Signal - 🟢 both; 🟡 one; 🔴 none
    Weight / confidence - 0.9 / 0.8
    Data sources - SEC EDGAR, Yahoo Finance – Financials

    Goodwill %, Organic Growth — Be wary of M&A-led growth

    Evaluation metrics - % revenue from M&A, goodwill/intangibles %, integration costs
    Method & thresholds - Split organic vs. inorganic; goodwill/assets < 25%
    Signal - 🟢 <25%; 🟡 25–35%; 🔴 >35%
    Weight / confidence - 0.6 / 0.7
    Data sources - 10-K/Q footnotes on acquisitions; purchase accounting notes

    TAM, SAM, SOM — Brand/TAM expansion creates value

    Evaluation metrics - New geo/segment revenue mix, brand extension margins
    Method & thresholds - Track mix shift; ≥ 10% of revenue from new TAM in last 4Q
    Signal - 🟢 ≥10%; 🟡 5–10%; 🔴 <5%
    Weight / confidence - 0.6 / 0.6
    Data sources - Segment disclosures; Similarweb traffic shares

    Dispersion, Controversy Score — Seek a “fight” (asymmetry)

    Evaluation metrics - Estimate dispersion (stdev/mean), short-reports count, bear-case map
    Method & thresholds - Favor high dispersion with improving revisions
    Signal - 🟢 both; 🟡 one; 🔴 none
    Weight / confidence - 0.5 / 0.5
    Data sources - Consensus providers (e.g., Koyfin); public short research

    Secular Beta — Ride long-term megatrends

    Evaluation metrics - % revenue tied to AI/EV/Clean-energy/etc.; beta vs. theme index
    Method & thresholds - Map products to themes; ≥ 30% revenue to trend
    Signal - 🟢 ≥30%; 🟡 15–30%; 🔴 <15%
    Weight / confidence - 0.6 / 0.6
    Data sources - Theme ETFs (XLK, ICLN, etc.), industry reports

    Cannibalization, Net Additive — Watch for self-cannibalization

    Evaluation metrics - New vs. legacy margin mix, attach/upgrade rates, cohort ARPU
    Method & thresholds - Cohort analysis; net revenue additive > 0
    Signal - 🟢 additive > 0; 🟡 ≈0; 🔴 negative
    Weight / confidence - 0.5 / 0.5
    Data sources - Cohort/KPI disclosures in earnings decks

    Channel Capacity — Beware hockey-stick without distribution

    Evaluation metrics - Pipeline-to-rev conversion, active resellers/slots capacity
    Method & thresholds - Capacity supports ≥ 80% of guide
    Signal - 🟢 ≥80%; 🟡 60–80%; 🔴 <60%
    Weight / confidence - 0.6 / 0.6
    Data sources - Channel partner counts; distributor listings; CRM proxies

    💰 Valuation & Timing¶

    FCF Yield, EV/EBIT, IRR — Know intrinsic value vs. price

    Evaluation metrics - DCF range, FCF yield, EV/EBIT, EV/S vs. growth, implied IRR
    Method & thresholds - DCF + comps band; FCFy > 5% or EV/EBIT < 12x
    Signal - 🟢 cheap band; 🟡 borderline; 🔴 expensive
    Weight / confidence - 1.0 / 0.8
    Data sources - SEC EDGAR, Yahoo Finance – Statistics, Koyfin

    PEG, LT Growth — High P/Es require high future growth

    Evaluation metrics - PEG = P/E ÷ LT growth, reinvestment runway
    Method & thresholds - PEG < 1.5 preferred
    Signal - 🟢 <1.5; 🟡 1.5–2; 🔴 >2
    Weight / confidence - 0.7 / 0.7
    Data sources - Consensus estimates (broker feeds/Koyfin); price data (Yahoo)

    Accretive Buyback, WACC — Buybacks accretive if E/P > after-tax cost of capital

    Evaluation metrics - E/P vs. after-tax cost of debt/return on cash; buyback % of float
    Method & thresholds - Spread = E/P − after-tax CoD; require > 0
    Signal - 🟢 positive spread; 🟡 ≈0; 🔴 negative
    Weight / confidence - 0.7 / 0.8
    Data sources - Financials; rate data (FRED)

    GM Compression — Price cuts rarely add value

    Evaluation metrics - Gross-margin trend post cut; competitor response time
    Method & thresholds - Event study ±2 quarters; GM recovers within 2Q?
    Signal - 🟢 recovers; 🟡 partial; 🔴 continues down
    Weight / confidence - 0.4 / 0.5
    Data sources - Earnings releases/decks; pricing trackers

    📈 Daily Trade Signals¶

    Momentum (RSI, MACD, Moving Averages) — Ride the wave

    Evaluation metrics - RSI(14), MACD histogram, 20/50/200-day MA crossovers
    Method & thresholds - RSI < 30 = oversold; > 70 = overbought; MACD > 0 bullish
    Signal - 🟢 aligned bullish; 🟡 mixed; 🔴 bearish
    Weight / confidence - 0.7 / 0.8
    Data sources - TradingView, Yahoo Finance

    Volume Breakouts — Confirm price moves with volume

    Evaluation metrics - Volume vs. 50-day average, VWAP
    Method & thresholds - Volume > 150% of average on breakout day
    Signal - 🟢 confirms; 🟡 weak; 🔴 absent
    Weight / confidence - 0.6 / 0.7
    Data sources - Finviz, Barchart

    ATR Volatility & Stop Placement — Protect capital

    Evaluation metrics - Average True Range (ATR)
    Method & thresholds - Stop = 1–2 × ATR below entry for longs
    Signal - 🟢 risk defined; 🟡 loose; 🔴 undefined
    Weight / confidence - 0.5 / 0.8
    Data sources - StockCharts

    🛡️ Risk Management & Exit¶

    Downside Liquidity, DSCR, Covenants — Define the bear case

    Evaluation metrics - Bear-case EPS/FCF, runway, DSCR, covenant headroom
    Method & thresholds - Stress −20% rev, +200 bps rates; liquidity ≥ 12m runway
    Signal - 🟢 ≥12m; 🟡 6–12m; 🔴 <6m
    Weight / confidence - 0.8 / 0.7
    Data sources - 10-K/Q, credit agreements (EDGAR exhibits)

    Quality Short, Z-Score — Short bad businesses (not just high P/E)

    Evaluation metrics - FCF < 0 persistence, leverage, deteriorating unit economics
    Method & thresholds - Composite “bad biz” score > 0.7
    Signal - 🟢 >0.7 (candidate); 🟡 0.5–0.7; 🔴 <0.5
    Weight / confidence - 0.6 / 0.6
    Data sources - Financial statements (EDGAR), price data (Yahoo)

    Exit Rules — Sell discipline (target hit or thesis broken)

    Evaluation metrics - Price vs. target; KPI breach; stop-loss rule
    Method & thresholds - Alert when price ≥ target or KPI breach; enforce stop-loss
    Signal - 🟢 action; 🟡 watch; 🔴 hold
    Weight / confidence - 1.0 / 0.9
    Data sources - Your memo targets; live prices (Yahoo Finance)
